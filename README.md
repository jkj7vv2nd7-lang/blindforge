# BlindForge

**無刻印ダンジョンで極める、完全ブラインドタッチ特化型RPG**

`BlindForge` は、「手元を見ないと打てない」を最短で卒業するために設計された、単一HTML完結型のブラウザRPGタイピングアプリです。  
最初から全キーを打たせるのではなく、**1F（ホームポジション F/J）から10本の指を1段ずつ解放**しながらモンスターを討伐し、段階的にキートップの印字を消していく（表示 → 薄字 → 完全無刻印）ことで、無理なく「見ないで打つ空間記憶」が身につきます。

## 既存タイピングアプリとの違い

| 特徴 | 一般的なタイピングアプリ | BlindForge |
| :--- | :--- | :--- |
| **手元を見てしまう問題** | 見てもスコアが出るため癖が直らない | **完全無刻印モード（印字ゼロ）**＋**暗視倍率ボーナス（1.5x〜）**で画面集中を促す |
| **学習カリキュラム** | 最初から全キー混合で挫折しやすい | **1F〜7Fの段階的10指解放システム**で基礎から日本語・コードまで順習 |
| **弱点克服** | 全体のWPM表示のみ | **26キー熟練度ヒートマップ**から苦手キーだけを混ぜた**特訓モンスター**を自動召喚 |
| **継続の仕組み** | 単調なスコア計測 | **RPGバトル（詠唱ゲージ・装備強化・デイリーミッション）**で毎日開きたくなる |

## GitHub Pages での公開方法

1. GitHubで新しい公開リポジトリ（例：`blindforge`）を作成します。
2. 同梱の `index.html`、`README.md`、`manual.md` をリポジトリのルートへアップロードします。
3. **Settings → Pages** を開き、Source を `Deploy from a branch`（`main` / `/ (root)`）に設定して **Save** をクリックします。
